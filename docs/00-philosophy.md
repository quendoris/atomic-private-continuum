# A.P.C. Philosophy

## Atomic Private Continuum

A.P.C. is a local-first encrypted data model designed around atomic state changes, private ownership of data, and deterministic synchronization.

Core principles:

- Transport is not trusted.
- Synchronization is not semantic.
- Merge decisions belong exclusively to the local model.
- Data exists as independent atomic domains.
- Encryption boundaries are part of the architecture, not an external feature.

A.P.C. does not attempt to hide impossible failures. Loss of keys means loss of data. Privacy is achieved through architecture, not promises.

## Design direction

The project prioritizes correctness, reproducibility, and user control over monetization, analytics, advertising, or platform dependency.

The goal is not to create another note application. The goal is to create a reliable open data foundation that applications can build on.
